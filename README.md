> JellyWisp provides a focused, desktop-native interface for streaming from your self-hosted Jellyfin media server, wrapping a modern web UI into a portable Windows application.

---

## ✨ Features
* **🎵 Dedicated Music Player:** A streamlined interface focused purely on audio playback, keeping your media library organized and accessible.
* **🔌 Jellyfin Integration:** Connects directly to your self-hosted Jellyfin server to fetch playlists, albums, and tracks.
* **📦 Portable Desktop Build:** Ships as a self-contained, unpacked `.exe` that can be run from any local directory or USB drive without a formal installation process.
* **🎨 Modern UI:** Built with React and Tailwind CSS for a responsive, clean, and customizable aesthetic.

## 🎯 Goals
* **Self-Hosted First:** Prioritize a seamless, native-feeling experience for users managing their own home media servers.
* **Lightweight Footprint:** Avoid the bloat of full web browsers by keeping the Electron wrapper performant.
* **Frictionless Portability:** Allow the client to be moved seamlessly between a primary desktop and a portable development laptop simply by copying the directory.
